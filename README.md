# Conversor de Unidades

Este es un programa realizado en **C#** que permite hacer diferentes conversiones de temperatura y distancia desde la consola.

## ¿Qué puede hacer?

El programa muestra un menú en el que se puede elegir entre las siguientes opciones:

* Celsius a Fahrenheit
* Fahrenheit a Celsius
* Kilómetros a Millas
* Millas a Kilómetros
* Salir del programa

Después de elegir una opción, se ingresa el valor que se quiere convertir y el programa muestra el resultado.

## Lo que se utilizó

Para realizar el programa se utilizaron algunos conceptos básicos de C# como:

* Variables
* `if` y `else`
* `switch`
* `do while`
* Métodos
* `TryParse`
* Entrada y salida de datos por consola

También se agregó una validación para evitar que el programa tenga problemas cuando se ingresa un dato que no es numérico.

## Ejemplo

```text
Seleccione una opción: 1
Ingrese los grados Celsius: 25

25.00 °C = 77.00 °F
```
